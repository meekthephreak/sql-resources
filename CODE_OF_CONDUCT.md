# Code of Conduct

Participants should communicate respectfully, welcome questions at all skill levels, and give specific, constructive feedback. Critique ideas and code without personal attacks.

Harassment, threats, discriminatory language, unwanted sexual attention, and publishing someone's private information are unacceptable. Do not share real credentials or sensitive operational records in examples, issues, or pull requests.

These expectations apply to this repository's issues, pull requests, and other project spaces. The maintainer may edit or remove harmful content, close discussions, or restrict participation when needed. Enforcement should be proportionate and consistent.

For concerns that can be discussed safely in public, contact the maintainer through a GitHub issue. For private concerns, contact meekthephreak@gmail.com. Do not disclose sensitive details in a public issue.
